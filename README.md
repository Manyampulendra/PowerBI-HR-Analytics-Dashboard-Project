
# 📊 HR Analytics Dashboard | Power BI

## 📌 Project Overview

The HR Analytics Dashboard is developed using Power BI to analyze employee data and gain meaningful insights into workforce trends.

The dashboard helps HR teams monitor employee attrition, understand department-wise employee distribution, and identify factors influencing employee retention. It supports data-driven decision-making through interactive visualizations and key performance indicators (KPIs).

## 🎯 Project Objectives

- Analyze employee attrition trends.
- Identify factors affecting employee retention.
- Monitor important HR performance indicators.
- Analyze employee demographics and workforce distribution.
- Support data-driven HR decision-making.

## 📊 Key KPIs & Insights

- Total Employees
- Total Attrition Count
- Attrition Rate
- Active Employees
- Average Employee Age
- Attrition by Department
- Attrition by Job Role
- Attrition by Gender
- Attrition by Years at Company

## 🛠️ Tools & Technologies Used

| Tool / Technology | Purpose |
|---|---|
| Power BI Desktop | Dashboard development and visualization |
| Microsoft Excel | Dataset |

| DAX | KPI calculations and measures |
| Data Visualization | Presenting HR insights |
